Pixel Toys visual reset, not another dashboard skin.

这 10 个方向抛开旧控制台、旧深蓝玻璃、旧后台卡片。重点是当代站点级设计语言、动效组织、交互概念和产品记忆点。

01fluid material

Liquid Production Surface

像 Apple 空间材质和创作面板结合，流程漂浮在半透明层级里。动效是面板折叠、流体聚焦、局部放大。

02editorial gallery

Gallery Production Wall

把项目当成展览墙，不像后台。镜头、资产、视频是作品卡片，交互是横向策展和局部展开。

03ambient ai

Ambient Generation Field

生成任务不是列表，而是一个有呼吸感的场。节点随状态移动，失败和等待用空间距离表达。

04split identity

Split Screen Studio OS

左侧白色决策区，右侧黑色预览区。强对比、少装饰，像高端创意软件官网进入产品态。

05spatial stack

Spatial Workflow Stack

所有流程以 3D 层叠卡片存在，不是平面表格。动效是镜头穿梭、层级拉近、任务压入队列。

06soft operating

Soft Creator Operating System

柔和、低压、现代生产力工具感。适合长期使用，靠排版、微动效和轻量状态建立高级感。

07neo noir

Neo Noir Film Machine

不是老式剪辑台，而是电影品牌站里的工具界面。黑、荧光黄、硬切场景转场，动效像片头。

08tactile ui

Tactile Object Interface

界面像可触摸物件。按钮、流程、镜头都是实体块，动效是推、压、吸附，避免传统软件味。

09kinetic type

Kinetic Type Workflow

用文字本身做界面。流程切换时大字重组，状态像字幕轨，适合强 CSSDA 视觉表达。

10motion first

Motion First Production Map

先定义动效，再长出界面。所有模块围绕生成中的状态迁移，适合做成有记忆点的产品首页。
