# Context

goal: 让独立编剧 Agent 的历史创作可见、可检索、可继续，避免用户因更换浏览器会话或 URL 而误以为剧本丢失。
user: 已登录的管理员创作者，连续创作多部 TK 短剧或普通长剧，可能在不同时间返回同一作品。
JTBD: 打开 PixelTale 后，在 2 秒内找到最近的剧本，看到当前阶段和进度，并继续原会话。
constraints: 复用现有独立 PixelTale session 存储与白色磨砂网格 UI；不改变阶段生产逻辑；不删除或覆盖旧数据；不触发模型或媒体生成。
success: 已保存会话可在“创作历史”中按更新时间显示；点击“继续创作”恢复相同 session；空历史、加载失败和当前会话状态清晰可见。
scope v1: [服务端历史摘要接口, 创作历史弹窗, 当前阶段与确认进度, 会话恢复, 新建剧集与历史互不覆盖]
non-goals: [全文搜索, 删除历史, 多用户共享, 旧数据内容重建, 模型生成]
open assumptions: [PixelTale 当前仅对管理员开放; 既有 session 目录是创作历史的事实来源]
risks: [若旧剧本只存在浏览器内存且未写入 pixel_tale_state.json，服务端历史模块无法凭空恢复；此类情况需要后续增加客户端草稿备份]
